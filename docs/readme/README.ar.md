تقارن **HTML Merge** بين مجلدين، أو بين ملفين، جنبًا إلى جنب — مثل WinMerge، لكن كملف HTML واحد
يعمل في أي متصفح حديث على Windows وmacOS وLinux وChromeOS وAndroid وiOS. اختر مجلدين فتظهر قائمة
بكل ملفات الاثنين وما حدث له: متطابق، مختلف، في اليسار فقط، في اليمين فقط. افتح ملفًا فتظهر
نسختاه جنبًا إلى جنب، مع تلوين الصياغة لأكثر من أربعين لغة، والكلمات المتغيّرة مُحدَّدة داخل
الأسطر المتغيّرة، وخريطة لكل الاختلافات بجانب شريط التمرير.

إنها لا تقوم إلا بالقراءة. لا شيء يُثبَّت، ولا شيء يُرفَع، ولا يتغيّر أي ملف أبدًا: الملفات تُقرأ
من الصفحة نفسها، في المتصفح، والصفحة لا يمكنها الوصول إلى الشبكة إطلاقًا.

تعمل الصفحة نفسها أيضًا كتطبيق ويب تقدمي (PWA): عند تقديمها من GitHub Pages يمكن تثبيتها في
النظام فتعمل بعدها كتطبيق منفصل، بنافذته وأيقونته الخاصتين، وتعمل دون اتصال — انظر
"[GitHub Pages](#github-pages)".

**عرض تجريبي عبر الإنترنت: [merge.marketkernel.com](https://merge.marketkernel.com/)**

![HTML Merge: نسختان من ملف جافاسكربت جنبًا إلى جنب](../html-merge.png)

## كيفية الاستخدام

1. ابنِ `build/html-merge.html` (انظر "[البناء](#البناء)") أو خذه من إصدار منشور، وافتحه في
   متصفح — فتحه مباشرة من القرص يكفي.
2. اختر الجانب الأيسر والأيمن: **مجلد…** أو **ملف…** لكل منهما، أو اسحب مجلدًا أو ملفًا وأفلِته
   في مربعه. مجلدان أو ملفان يُفلَتان على النافذة معًا تتم مقارنتهما فورًا.
3. **قارن**.

مع مجلدين، تظهر قائمة المجلدات وتمتلئ مع مقارنة الملفات. الشرائح في الأعلى تُظهر أو تُخفي كل نوع
من النتائج وتَعُدّه؛ يمكن أن تكون القائمة شجرة أو قائمة مسطحة من المسارات، تُصفَّى حسب الاسم
(`util`، أو نمط مثل `*.ts`)، وتُرتَّب حسب أي عمود. انقر نقرًا مزدوجًا على ملف (أو حدده واضغط
Enter) لمقارنته؛ `]` و`[` تنقلان إلى الملف المختلف التالي والسابق، وEsc أو زر الرجوع في المتصفح
يعيدان إلى القائمة.

في شاشة الملف:

- الأسهم تتنقل بين الاختلافات (Alt+↓ وAlt+↑، أو F7 وShift+F7)؛ الاختلاف الحالي محدَّد في الهامش،
  والخريطة على اليمين تُظهر مكان كل الاختلافات — انقر عليها للقفز إليها؛
- **جنبًا إلى جنب أو الواحد تحت الآخر** يبدّل بين لوحتين ولوحة موحّدة؛
- **طي الأسطر المتطابقة** يُخفي المقاطع الطويلة المتطابقة، تاركًا بضعة أسطر حول كل اختلاف؛ انقر
  على طيّة لفتحها؛
- **بحث** (Ctrl+F، ⌘F على ماك) يُحدِّد كل تطابق في الجانبين؛ Enter وShift+Enter تنقلان بينها؛
- قائمة **⋯** تضم خيارات العرض والمقارنة: التخطيط، اللغة التي تُلوَّن بها الملفات، ألوان الصياغة،
  المسافات البيضاء ونهايات الأسطر الظاهرة، الكلمات أو الأحرف داخل الأسطر المتغيّرة، وما يُتجاهَل.

الصور (PNG وJPEG وGIF وWebP وBMP وICO وAVIF) تُعرَض جنبًا إلى جنب مع حجمها بالبكسل. الملفات
الثنائية الأخرى تُقارَن بايتًا ببايت: تقول الصفحة إن كانت متطابقة أم لا، وأين أول اختلاف، وتُظهر
البايتات المحيطة به.

يتذكر Chrome وEdge المقارنات الأخيرة: تُدرَج في شاشة البداية وتُفتَح مجددًا بنقرة واحدة (يطلب
المتصفح الإذن لقراءة المجلدات مرة أخرى). المتصفحات الأخرى تختار المجلدات من جديد في كل مرة.

### على الهاتف

تعمل الصفحة على شاشة الهاتف: شاشة البداية تُكدِّس الجانبين، وقائمة المجلدات تُبقي الاسم والنتيجة،
وزوج الملفات يُعرَض الواحد تحت الآخر. اضغط على ملف لفتحه. على Android، يختار Chrome المجلدات
والملفات معًا؛ iOS يمكنه مقارنة الملفات فقط (لا يمكن اختيار المجلدات فيه).

## الميزات

- **المجلدات**: مقارنة تكرارية حسب المحتوى (أو، بشكل أسرع، حسب الحجم والتاريخ)؛ شجرة أو قائمة
  مسطحة؛ تصفية حسب النتيجة والاسم؛ ترتيب حسب الاسم أو النتيجة أو الحجم أو التاريخ؛ أسماء مستبعدة
  بنمط (`.git; node_modules; *.log; build/`)؛ مقارنة أسماء الملفات مع تجاهل حالة الأحرف أو بدونه؛
  الحالات تمتلئ أثناء قراءة الملفات، قليلًا في كل مرة، حتى تُظهر المجلدات الكبيرة شيئًا على الفور.
- **النص**: مقارنة صبورة (patience diff) فوق خوارزمية Myers، بحيث لا تُقرَن الأقواس والأسطر
  الفارغة المنقولة بكود غير مرتبط؛ أسطر الكتلة المتغيّرة تُقرَن حسب مدى تشابهها؛ الكلمات أو
  الأحرف المتغيّرة مُحدَّدة داخل السطر؛ كتل الأسطر الفارغة يمكن تجاهلها؛ العرض الموحّد؛ طي
  الأسطر المتطابقة؛ بحث عبر الجانبين.
- **خيارات المقارنة**: تجاهل تغييرات المسافات البيضاء أو كل المسافات البيضاء، تجاهل حالة الأحرف،
  تجاهل الأسطر الفارغة، تجاهل نهايات الأسطر (CRLF وLF وCR) — في قائمة المجلدات وشاشة الملف على حد
  سواء.
- **الترميز**: UTF-8، وUTF-8 مع BOM، وUTF-16 LE وBE، وWindows-1252 للملفات غير الصالحة بترميز
  UTF-8؛ يظهر الترميز ونهايات الأسطر وعدد الأسطر لكل جانب، ويُسمَّى اختلاف نهايات الأسطر وحده
  باسمه.
- **تلوين الصياغة** لأكثر من أربعين لغة، يُختار حسب اسم الملف أو سطره الأول
  (`#!/usr/bin/env python3`): JavaScript وTypeScript وJSON وHTML (مع السكربتات والأنماط بداخله)
  وXML وCSS وSCSS وLess وMarkdown وPython وJava وKotlin وC وC++ وC# وGo وRust وSwift
  وObjective-C وPHP وRuby وshell وPowerShell وملفات batch وSQL وYAML وTOML وINI وDockerfile
  وMakefile وCMake وdiff وLua وPerl وR وDart وScala وGroovy وHaskell وElixir وGraphQL
  وProtocol Buffers وPascal وVisual Basic. يمكن اختيار أي لغة أخرى يدويًا.
- **الملفات الكبيرة**: تُرسَم الأسطر المرئية فقط، فتمرّر الملفات ذات مئات آلاف الأسطر بسلاسة؛
  الأسطر الطويلة جدًا تُقطَع على الشاشة (المقارنة ما زالت ترى كل شيء).
- **الصور والملفات الثنائية** كما وُصف أعلاه.
- **سبع عشرة لغة** للواجهة، من اليمين إلى اليسار للعربية والأردية؛ مظهر فاتح ومظهر داكن يتبعان
  النظام أو يُختاران يدويًا.
- التطبيق المثبَّت يُحدِّث نفسه فقط عند الطلب: انظر "[GitHub Pages](#github-pages)".

## الأمان

- **القراءة فقط.** تقرأ الصفحة الملفات ولا تكتب أو تُعيد تسمية أو تحذف أي شيء أبدًا. في Chrome
  وEdge تُفتَح المجلدات عبر File System Access API بإذن قراءة فقط.
- **عدم الاتصال بالتصميم.** سياسة أمان المحتوى (Content-Security-Policy) للصفحة تنص على
  `connect-src 'none'`، وكل ما تحتاجه — الأنماط والكود والأيقونات — داخل ملف HTML الواحد. لا
  يمكنها تحميل أي شيء أو إرسال أي شيء، مهما كان محتوى الملف المُقارَن.
- **سكربت مثبَّت.** يستبدل البناء `script-src 'unsafe-inline'` بتجزئة السكربت الوحيد في الصفحة:
  فحتى لو تسرّب اسم ملف أو سطر نص يومًا دون تهريب، فلن يعمل أي معالج داخلي فيه. النص القادم من
  الملفات يصل إلى الصفحة مُهرَّبًا (escaped).
- المقارنات الأخيرة (في Chrome وEdge) تحتفظ فقط بمقابض المجلدات في IndexedDB الخاصة بالمتصفح —
  دون أسماء ملفات بداخلها، ودون محتوى. الإعدادات تُحفَظ في `localStorage`.

## الترجمات

تتحدث الواجهة الإنجليزية والصينية والهندية والإسبانية والفرنسية والعربية والبنغالية والبرتغالية
والروسية والأردية والإندونيسية والألمانية واليابانية والماراثية والتيلوغوية والتركية والأوكرانية.
تبدأ بأول لغة من لغات المتصفح تعرفها؛ الإعدادات ← اللغة تختار لغة أخرى.

- تعيش الإنجليزية في الكود: `t('context', 'English text')`، أو
  `tn('context', '{count} file', '{count} files', n)` لنص فيه عدد. في `src/app/template.html`
  الشيء نفسه هو `data-i18n="context"` (نص العنصر) و`data-i18n-attr="context"` (عنوانه، والنص
  التوضيحي، وaria-label).
- كل لغة أخرى قاموس، `src/locales/<code>.json`:
  `{ "context": { "English text": "translation" } }`. النص الذي فيه عدد له صيغة واحدة لكل فئة
  جمع في اللغة (`Intl.PluralRules`)، مفتاحها صيغة الجمع الإنجليزية.
- كل ما ينقصه قاموس يظهر بالإنجليزية.
- `npm run i18n` تطبع، لكل لغة، النصوص الناقصة من قاموسها والنصوص التي بها والتي لم تعد الواجهة
  تستخدمها؛ `npm test` تتحقق من العناصر النائبة وصيغ الجمع.

## البناء

يحتاج Node.js الإصدار 20 أو أحدث.

```sh
npm install
npm run build        # build/html-merge.html و build/pages/
npm run watch        # يعيد البناء مع كل تغيير
npm run check        # فحص الأنواع، الاختبارات، البناء، اختبارات المتصفح
```

`./build.sh` تفعل الشيء نفسه مثل `npm run build`، وتُثبِّت التبعيات في أول تشغيل. التبعيتان
الوحيدتان هما esbuild وTypeScript، وكلتاهما للبناء فقط؛ الصفحة نفسها لا تستخدم أي مكتبة.

- `npm test` تُشغِّل اختبارات الوحدة في Node: الاختلاف، الصفوف والطي، الترميز، مُلوِّن الصياغة
  وقواعده، مقارنة المجلدات، القواميس.
- `npm run test:browser` تُشغِّل الصفحة المبنية وتطبيق PWA في Chrome بلا واجهة (headless)، عبر
  بروتوكول DevTools، دون أي تبعية أخرى. تحتاج إلى Chrome أو Chromium محليًا
  (`CHROME=/path/to/chrome` لاختيار واحد) وتُتجاوَز عند عدم وجوده.
- `npm run shots -- <dir>` تحفظ لقطات شاشة لكل شاشة رئيسية.
- `npm run icons` تُولِّد أيقونات PNG لتطبيق PWA من `assets/icon.svg`.

## الإصدارات والإطلاقات

يعيش الإصدار في `package.json` فقط. بناء الالتزام (commit) الموسوم بـ `v<version>` يُظهره كما هو؛
أي بناء آخر يضيف الالتزام الخاص به (`0.1.0+1a2b3c4`)، فلا تُؤخَذ صفحة مبنية من `main` على أنها
إصدار منشور. يظهر الإصدار أسفل شاشة البداية وفي الإعدادات.

للإصدار: `npm version minor` (أو `patch`)، ثم `git push --follow-tags`. الوسم (tag) يُشغِّل
`.github/workflows/release.yml`، الذي يتحقق من تطابق الوسم مع `package.json`، ويُشغِّل
الاختبارات، ويُرفِق `html-merge-v<version>.html` و`SHA256SUMS.txt` بإصدار GitHub.

## GitHub Pages

هذا المستودع منشور على <https://merge.marketkernel.com/>.

`build/pages/` هي الصفحة نفسها كتطبيق PWA قابل للتثبيت: بيان (manifest)، وأيقونات، وعامل خدمة
(service worker) يُبقيها تعمل دون اتصال. `.github/workflows/pages.yml` يبنيها ويختبرها وينشرها
على GitHub Pages مع كل دفعة (push) إلى `main` (الإعدادات ← Pages ← المصدر: GitHub Actions). كل
مساراتها نسبية، فتعمل تحت عنوان موقع مشروع مثل `/<repo>/`.

- سياسة أمان المحتوى لتطبيق PWA تضيف فقط أصله الخاص للبيان والعامل والأيقونات؛ `connect-src`
  تبقى `'none'`.
- النشر الجديد لا يستبدل النسخة العاملة من تلقاء نفسه: عامل الخدمة الجديد ينتظر، وتقول الإعدادات
  (وشاشة البداية) "الإصدار X جاهز. تحديث". تتحقق الصفحة بهدوء كل ست ساعات وعند عودة الاتصال.
- بعد التحديث، تُقال "تم التحديث إلى الإصدار X" مرة واحدة.

## القيود

- **القراءة فقط بالتصميم**: لا دمج ولا تحرير؛ انسخ التغييرات في محررك.
- يختار Firefox وSafari المجلدات عبر حوار رفع المجلدات الخاص بالمتصفح: يقرأ المجلد كله دفعة
  واحدة (الأسماء المستبعدة تُترَك لاحقًا، لا تُتجاوَز)، ولا يُظهر المجلدات الفارغة، والتحديث لا
  يرى الملفات المضافة منذ ذلك — اختر المجلدين من جديد لذلك. iOS لا يمكنه اختيار المجلدات إطلاقًا.
- الملفات الأكبر من 64 ميغابايت تُقارَن بايتًا ببايت فقط، دون خيارات التجاهل.
- تلوين الصياغة معجمي (lexical) — الكلمات المفتاحية والسلاسل النصية والتعليقات والأعداد — وليس
  مُحلِّلًا (parser)؛ بعض التراكيب (وسوم JSX، heredocs) تُلوَّن كنص عادي.
- لا مقارنة ثلاثية، ولا مقارنة لمحتوى الأرشيفات، ولا كشف للكتل المنقولة.
